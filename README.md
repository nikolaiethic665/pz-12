# ПЗ 12. Язык документа, идентификаторы и якорная навигация

[Демонстрация](https://nikolaiethic665.github.io/pz-12/) · [Исходный код](https://github.com/nikolaiethic665/pz-12/tree/kolodei) · [Отчёт PDF](https://nikolaiethic665.github.io/pz-12/materials/report.pdf) · [Pull Request](https://github.com/nikolaiethic665/pz-12/pull/1)

## Цель

Освоить якорную навигацию и атрибуты языка.

## Задание

Указать язык документа и связать меню с разделами страницы.

## Реализация

У документа и английского заголовка указаны языки. Каждый раздел получил уникальный id. Пункты меню используют эти id как фрагменты URL. Ссылки «Наверх» ведут к шапке. scroll-margin-top оставляет место при прокрутке.
